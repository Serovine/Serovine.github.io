| 明日の僕がまだ待っている | *ashita no boku ga mada matte iru* | ตัวฉันในวันพรุ่งนี้กำลังรอคอยอยู่ |

| | | |
| どうせ幾年経って車が空飛べど | *douse ikunen tatte kuruma ga sora tobedo* | ต่อให้อีกหลายปีผ่านไปจนรถยนต์บินได้บนฟ้า |
| きっと何年経って機械が喋れども | *kitto nannen tatte kikai ga shaberedomo* | ต่อให้อีกหลายปีผ่านไปจนเครื่องจักรพูดคุยได้ |
| 何だって言いたいんだ 便利って言う前に | *nan datte iitai nda benri tte iu mae ni* | สิ่งที่ฉันอยากจะบอกก็คือ ก่อนที่โลกมันจะสะดวกสบาย |
| 心の傷口を治してくれ | *kokoro no kizuguchi o naoshite kure* | ช่วยมารักษาบาดแผลในใจให้ฉันก่อน |
| | | |
| あんな空でミサイルが飛ぶのなら | *anna sora de misairu ga tobu no nara* | ถ้าบนท้องฟ้าแบบนั้นมีขีปนาวุธบินว่อน |
| そんなもので幸せを乞うのなら | *sonna mono de shiawase o kou no nara* | ถ้าคนเราต้องร้องขอความสุขจากของพรรค์นั้น |
| 優しい人にならなくちゃ | *yasashii hito ni naranakucha* | ฉันก็คงเป็นคนที่อ่อนโยนได้อยู่สินะ |
| 僕は僕を肯定していけるかな | *boku wa boku o koutei shite ikeru kana* | ถ้าทำแบบนั้น ฉันจะสามารถยอมรับตัวเองได้ไหมนะ |
| | | |
| 頭を上げて前向けと言われても | *atama o agete mae muke to iwaretemo* | ถึงใครจะบอกให้เงยหน้าแล้วมองไปข้างหน้า |
| 暗闇じゃ前もクソもないな | *kurayami ja mae mo kuso mo nai na* | แต่ในความมืดมิดมันไม่มีอะไรให้มองทั้งนั้นแหละ |
| | | |
| 一人で居れど 二人で居れど | *hitori de iredo futari de iredo* | ไม่ว่าจะอยู่คนเดียว หรืออยู่สองคน |
| 孤独は孤独に変わりゃしねえ | *kodoku wa kodoku ni kawarya shinee* | ความเหงาก็ยังคงเป็นความเหงาไม่เปลี่ยนไปหรอก |
| | | |

| | | |
| だけれども それ程の事しか | *dakedo demo sore hodo no koto shika* | แต่ถึงอย่างนั้น ฉันก็หาคำพูดอื่นที่หลั่งไหลออกมาจากปากไม่ได้เลย |
| 口から溢れる言葉がどうしても見つからないや | *kuchi kara afureru kotoba ga doushitemo mitsukaranai ya* | นอกจากเรื่องพรรค์นั้น |

| 明日が来なければいいのにな | *ashita ga konekeba ii no ni na* | ถ้าวันพรุ่งนี้ไม่มาถึงเลยก็คงจะดี |

| どうせ愛なんてって薄幸ぶって強がっても | *douse ai nante tte hakkou butte tsuyogattemo* | ถึงจะทำปากเก่งว่าไม่สนเรื่องความรัก |
