เลื่อนลงเพื่ออ่าน

ในระยะเวลาเพียงประมาณ 4 ปี วงการ AI สร้างภาพ (Image Generation AI) ได้เปลี่ยนแปลงอย่างรวดเร็ว จากระบบที่ผู้ใช้ต้องจดจำ Keyword และ Tag จำนวนมาก ไปสู่โมเดลที่สามารถเข้าใจภาษามนุษย์ได้โดยตรง

แม้จะไม่มีการแบ่งยุคอย่างเป็นทางการ แต่หากพิจารณาจากสถาปัตยกรรมของโมเดล วิธีการเขียน Prompt และแนวทางการใช้งานของชุมชน สามารถแบ่งวิวัฒนาการออกได้เป็น 3 ยุค ดังนี้

ยุคแห่งการทดลอง Prompt

2022 – 2023

Stable Diffusion 1.x

โมเดลในยุคแรก ได้แก่ Stable Diffusion 1.4 และ 1.5

จุดเด่นของยุคนี้คือการทำให้ AI สร้างภาพสามารถใช้งานบนเครื่องคอมพิวเตอร์ทั่วไปได้ โดยใช้โมเดลแบบ Latent Diffusion ซึ่งถือเป็นจุดเปลี่ยนสำคัญของวงการ Open Source

  • ความละเอียดพื้นฐาน 512×512 พิกเซล
  • ใช้ CLIP Text Encoder ที่มีข้อจำกัดด้าน Context ทำให้ Prompt ที่ยาวมากเริ่มสูญเสียประสิทธิภาพ
  • ยังไม่มีมาตรฐานการเขียน Prompt
  • ผู้ใช้ส่วนใหญ่คัดลอก Prompt จากเว็บไซต์อย่าง Civitai หรือ Lexica แล้วนำมาปรับแต่งต่อ
  • งานที่ได้รับความนิยมส่วนใหญ่เป็นภาพแนว Photorealistic

ในช่วงเวลานี้ การสร้างภาพที่ดีขึ้นอยู่กับ "การสะสม Keyword" มากกว่าการอธิบายภาพด้วยภาษามนุษย์

กล่าวได้ว่า ผู้ใช้ต้องเรียนรู้ "ภาษา" ของ AI มากกว่าให้ AI เข้าใจภาษาของผู้ใช้

ยุคแห่ง Prompt Engineering

ปลายปี 2023 – 2025

Stable Diffusion XL (SDXL)

การเปิดตัว Stable Diffusion XL หรือ SDXL ถือเป็นก้าวกระโดดครั้งสำคัญ

นอกจากความละเอียดพื้นฐานที่เพิ่มเป็น 1024×1024 พิกเซล แล้ว โมเดลยังสามารถตีความ Prompt ได้แม่นยำขึ้น รองรับรายละเอียดขององค์ประกอบภาพได้ดีกว่า SD1.x อย่างชัดเจน

นี่คือยุคที่คำว่า Prompt Engineering เริ่มได้รับความนิยม

ผู้ใช้จำนวนมากพัฒนา Prompt Format ที่มีรูปแบบคล้ายกัน โดยอ้างอิง Tag จาก Danbooru ซึ่งกลายเป็นมาตรฐานของวงการ Anime AI ในเวลาต่อมา

1girl, solo, smile, looking at viewer, masterpiece, best quality ...

การเรียงลำดับ Tag, การกำหนดน้ำหนัก (Weights) และการจัดโครงสร้าง Prompt กลายเป็นทักษะสำคัญของผู้ใช้งาน

การกำเนิด "จตุรเทพ" โมเดลสาย Anime

ในชุมชนผู้ใช้งาน มีการเรียกโมเดลยอดนิยมว่า "จตุรเทพ" แม้จะมีแนวทางการเทรนแตกต่างกัน แต่ทั้งหมดล้วนผลักดันคุณภาพของงาน Anime ไปอีกระดับ และกลายเป็น Base Model สำหรับ Fine-tune และ LoRA อีกนับพันรุ่น

ยุคของ Natural Language

2025 – ปัจจุบัน

จากภาษาของ AI สู่ภาษาของมนุษย์

หากยุค SDXL คือการทำให้มนุษย์เรียนรู้ภาษาของ AI

ยุคปัจจุบันคือการทำให้ AI เรียนรู้ภาษาของมนุษย์แทน

โมเดลรุ่นใหม่จำนวนมากเปลี่ยนจากการพึ่งพา Danbooru Tag เป็นการใช้ Natural Language Prompt หรือการอธิบายภาพด้วยภาษาปกติ

Danbooru Tag

เรียง Tag หลายสิบหรือหลายร้อยคำ ต้องจำโครงสร้าง กำหนดน้ำหนัก และเรียงลำดับความสำคัญ

VS

Natural Language

อธิบายภาพด้วยประโยคธรรมดา เหมือนพูดคุยกับคน ไม่ต้องจำโครงสร้างซับซ้อน

"เด็กผู้หญิงกำลังนั่งอ่านหนังสือใต้ต้นซากุระในช่วงพระอาทิตย์ตก โทนภาพอบอุ่นแบบภาพยนตร์"
  • ใช้ Large Language Model หรือ Text Encoder รุ่นใหม่ที่สามารถตีความข้อความได้ละเอียดกว่าเดิม
  • Prompt Adherence ดีขึ้นอย่างชัดเจน ไม่ยึดติดกับข้อจำกัดของ Context แบบ CLIP
  • ข้ามภาษาอังกฤษ ภาษาญี่ปุ่น ภาษาจีน ภาษาไทยได้
  • ส่วนใหญ่เน้นงาน Photorealistic และการเข้าใจภาษาธรรมชาติเป็นหลัก

การมาของ Anima

2026 — CircleStone Labs x Comfy Org — สร้างบน NVIDIA Cosmos

ในปี 2026 โมเดล Anima ได้เปิดตัวในฐานะโมเดล Open-weight สำหรับงาน Anime โดยพัฒนาร่วมกับ Comfy Org และสร้างขึ้นบนสถาปัตยกรรม NVIDIA Cosmos

สิ่งที่แตกต่างคือ Anima ไม่ได้ใช้ CLIP Text Encoder แบบเดิม แต่เปลี่ยนมาใช้ Qwen3-0.6B เป็น Text Encoder พร้อมกับ Qwen Image VAE ทำให้เข้าใจภาษาธรรมชาติได้ลึกกว่าเดิม ทั้งด้านความสัมพันธ์ของคำ ลำดับเหตุการณ์ และเจตนาของผู้สั่งงาน

ตัว Image Backbone ถูก Fine-tune ด้วยข้อมูลภาพอนิเมะหลายล้านภาพ ส่งผลให้ยังคงความสามารถในการเข้าใจคำสั่งแบบภาษาพูด ขณะเดียวกันก็รองรับ Danbooru Tag, Natural Language หรือแม้แต่การผสมทั้งสองรูปแบบไว้ใน Prompt เดียวกันได้อย่างเป็นธรรมชาติ

แนวทางดังกล่าวทำให้ผู้สร้าง Fine-tune และ LoRA จำนวนมากเริ่มย้ายจาก Illustrious มาสร้างโมเดลบน Anima เนื่องจากสามารถรักษาจุดแข็งของ Workflow เดิมไว้ได้ ขณะเดียวกันก็เปิดทางสู่การสั่งงานด้วยภาษามนุษย์อย่างเต็มรูปแบบ

บทสรุป

หากมองเฉพาะคุณภาพของภาพ ความแตกต่างระหว่างแต่ละยุคอาจไม่ชัดเจนนัก เพราะความสวยงามยังขึ้นอยู่กับข้อมูลที่ใช้เทรนและแนวทางของแต่ละโมเดล

แต่หากมองในมิติของ "การสื่อสารระหว่างมนุษย์กับ AI" จะเห็นการเปลี่ยนแปลงอย่างชัดเจน

ยุคที่ 1 — ผู้ใช้ต้องค้นหาและจดจำ Keyword
ยุคที่ 2 — ผู้ใช้ต้องเชี่ยวชาญ Prompt Engineering และ Danbooru Tag
ยุคที่ 3 — AI เริ่มเข้าใจภาษาธรรมชาติของมนุษย์ และยังรองรับ Tag แบบเดิมเมื่อจำเป็น

บทส่งท้าย

แม้ว่าโมเดลยุคที่ 3 จะลดความยุ่งยากของการเขียน Prompt ลงอย่างมาก และทำให้การสร้างภาพด้วย AI เป็นเรื่องที่เข้าถึงได้ง่ายกว่าเดิม แต่ก็ไม่ได้หมายความว่าโมเดลยุค SDXL จะหมดความสำคัญ

สำหรับผู้ใช้งานที่คุ้นเคยกับการเขียน Danbooru Tag หรือ Workflow แบบเดิม โมเดลในยุค SDXL ยังคงสร้างผลงานที่มีคุณภาพสูงได้ไม่แพ้โมเดลรุ่นใหม่ อีกทั้งระบบ Prompt แบบ Pipeline ที่ผ่านการขัดเกลามาหลายปียังให้การควบคุมรายละเอียดในระดับที่ผู้ใช้งานระดับสูงจำนวนมากยังคงชื่นชอบ

ท้ายที่สุดแล้ว การเปลี่ยนผ่านจากยุคที่ 2 สู่ยุคที่ 3 ไม่ใช่การ "แทนที่" แต่เป็นการ "เพิ่มทางเลือก"
