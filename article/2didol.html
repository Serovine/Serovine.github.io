📌PART 00 · OVERVIEW

ภาพรวม: มากกว่าวัฒนธรรมย่อยของโอตาคุ

💡 ข้อสรุปสำคัญของงานวิจัย

อุตสาหกรรม "ไอดอลสาวน้อย 2D" ในญี่ปุ่น ไม่ใช่เพียงปรากฏการณ์ทางวัฒนธรรมย่อยของโอตาคุ แต่ได้เติบโตจนกลายเป็น โครงสร้างธุรกิจขนาดใหญ่ ที่เชื่อมโยงอุตสาหกรรมต่าง ๆ เข้าด้วยกันอย่างแนบแน่น

🎮 เกม 📺 อนิเมะ 🎵 เพลง 🎫 ไลฟ์คอนเสิร์ต 🧸 สินค้า ✈️ การท่องเที่ยวเชิงคอนเทนต์ในพื้นที่จริง

จุดกำเนิดเชิงรูปแบบ มาจากอาร์เคดเกม 'THE IDOLM@STER' ในปี 2005 ซึ่งเป็นผู้นิยามบทบาท "โปรดิวเซอร์" และ "การสนับสนุน (โอชิ) ไอดอล" ผ่านเครือข่ายออนไลน์ในระดับประเทศ

หลังจากนั้น แฟรนไชส์ต่าง ๆ ผลัดกันขึ้นเป็นผู้นำเทรนด์ของแต่ละยุคสมัย โดยวัดจากทั้งรายได้และขนาดฐานแฟนคลับ:

Idolmaster→ Love Live!→ Aikatsu!→ Pretty Rhythm / PriPara→ BanG Dream!→ Uma Musume→ Hololive

ขณะเดียวกัน โมเดลธุรกิจแบบ Media Mix และ IP Developer เชิงรุก ที่บริษัทอย่าง Bandai Namco, Bushiroad, Cygames และ Cover Corp นำมาใช้ ได้ส่งผลกระทบเชิงโครงสร้างต่ออุตสาหกรรมไอดอล 3D (ศิลปินตัวจริง) ตั้งแต่รูปแบบไลฟ์ ไปจนถึงการสร้าง "ไลน์สินค้า" และ "แบรนด์แฟนคลับ" ที่พึ่งพา IP มากกว่าตัวบุคคล

งานนี้จัดวางไทม์ไลน์เชิงยุคสมัยจากอดีตจนถึงปัจจุบัน แบ่งตามแฟรนไชส์ที่เป็นผู้นำเทรนด์หลักในธุรกิจไอดอล 2D หญิง พร้อมสังเคราะห์ จุดพีค ขาขึ้น–ขาลง และผลกระทบระหว่างอุตสาหกรรมที่เกี่ยวข้องอย่างเป็นระบบ

🔍PART 01 · FRAMEWORK

บทนำ: กรอบการศึกษาวงการไอดอล 2D หญิงในญี่ปุ่น

"ไอดอล 2D" คืออะไร

🎤 นิยามในบริบทของงานนี้

ตัวละครหญิงในสื่ออนิเมะ เกม และสื่อดิจิทัลอื่น ๆ ที่ถูกสร้างขึ้นให้มีคุณลักษณะคล้าย "ไอดอล" คือ

  • มีการร้องเพลง เต้น และแสดงบนเวที
  • มีเรื่องเล่าเกี่ยวกับเส้นทางการเติบโต
  • มีความสัมพันธ์เชิง "สนับสนุน" ระหว่างแฟนคลับกับตัวละคร
  • เชื่อมต่อกับนักพากย์หรือศิลปินในโลกจริง ผ่านกิจกรรมอย่างคอนเสิร์ตที่นักพากย์แสดงบทบาทเป็นตัวละครนั้น ๆ "ไลฟ์ทอล์ค" และอีเวนท์ที่ผสมผสานตัวละครกับตัวบุคคลในระดับสูง
💡 Key Insight

ความเป็น "2D" ไม่ได้แปลว่ามีเพียงภาพสองมิติ หากแต่หมายถึงการที่ "ตัวละคร" หรือ IP เป็นศูนย์กลางของธุรกิจและคอมมูนิตี้ มากกว่าความเป็นศิลปินบุคคลแบบไอดอล 3D ดั้งเดิม

💴รายได้

อ้างอิงจากยอดขายเกมมือถือ ยอดขายสินค้าการ์ดเช่น Data Card Dress ของ Aikatsu! และข้อมูลรายได้ที่บริษัทผู้ถือ IP เปิดเผย เพื่อวัดทั้งส่วนแบ่งการตลาดและจุดพีคของแต่ละแฟรนไชส์และยุคสมัย

👥ฐานแฟนคลับ

🕹️PART 02 · THE ORIGIN

การกำเนิด: จากอาร์เคด 'THE IDOLM@STER' สู่โมเดล 2D Idol แบบใหม่

บริบทก่อนปี 2005: ยุคเกมจีบสาวและการทดลอง "ไอดอลในเกม"

ก่อนที่ 'THE IDOLM@STER' เวอร์ชันอาร์เคดจะเปิดให้บริการในปี 2005 ภูมิทัศน์ของเกมที่มีความสัมพันธ์กับ "ไอดอล" หรือหญิงสาวในบทบาทใกล้เคียงไอดอล ยังอยู่ภายใต้กรอบของเกมจีบสาว เช่น 'Tokimeki Memorial' ซึ่งเน้นโครงเรื่องโรแมนติกระหว่างตัวเอกชายกับตัวละครหญิง โครงสร้างเช่นนี้ทำให้ศูนย์กลางของประสบการณ์อยู่ที่ "ความรักแบบแฟนสาว" มากกว่าความเป็น "ศิลปิน" หรือ "นักแสดงบนเวที" ที่แฟนคลับร่วมกันสนับสนุน — แม้จะมีองค์ประกอบของการไล่ตามความฝันและการพัฒนาตัวละคร แต่เกมเหล่านี้ไม่ได้สร้างระบบธุรกิจรอบ "การโปรดิวซ์ไอดอล" และไม่ผูกกับกิจกรรมในโลกจริง เช่น คอนเสิร์ตของนักพากย์ในระดับอุตสาหกรรม

ในบริบทอาร์เคด ญี่ปุ่นช่วงปลายยุค 1990 ถึงต้น 2000 กำลังทดลองรูปแบบตู้เกมใหม่ ๆ โดยเฉพาะตู้ที่ใช้การ์ดและระบบเครือข่ายออนไลน์ เช่น โครงการ "Rewritable Stage" ของ Namco ซึ่งเป็นแพลตฟอร์มตู้เกมที่ใช้การ์ดเขียน–อ่านข้อมูลได้ใหม่ เพื่อเชื่อมต่อข้อมูลผู้เล่นและตัวละครข้ามเครื่องเล่น การทดลองนี้นำไปสู่เกม 'Dragon Chronicle' ในปี 2003 ซึ่งเป็นเกมใช้การ์ดบนตู้ Rewritable Stage รุ่นแรก และเป็นจุดตั้งต้นเชิงเทคโนโลยีที่ทำให้ Namco เริ่มมองหา "เกมอันดับสอง" บนแพลตฟอร์มเดียวกัน

ความสำเร็จของรายการออดิชันไอดอลทางโทรทัศน์ในช่วงต้นทศวรรษ 2000 และการขยายตัวของอินเทอร์เน็ตในร้านเกม ทำให้ทีมพัฒนาของ Namco เริ่มทดลองผสมผสานระหว่าง "ธีมไอดอล" กับระบบเครือข่ายอาร์เคด แนวคิดไม่ใช่การทำเกมจีบสาวอีกเกมหนึ่ง แต่เป็นการสร้างประสบการณ์แบบ "ออดิชันไอดอล" ที่ผู้เล่นหลายคนแข่งขันกันผ่านออนไลน์ — ผู้เล่นไม่ใช่คนรักของไอดอล แต่เป็น "โปรดิวเซอร์" ที่กำลังสร้างไอดอลให้ประสบความสำเร็จ

🔄 จุดหักเหของทั้งอุตสาหกรรม

การเปลี่ยนโครงความสัมพันธ์จาก "ความรัก" เป็น "การสนับสนุน (โอชิ)" — ซึ่งจะกลายเป็นหัวใจของโมเดลธุรกิจไอดอล 2D หญิงในยุคต่อมา

โครงการ Rewritable Stage และการพัฒนา Arcade 'THE IDOLM@STER'

'THE IDOLM@STER' เวอร์ชันอาร์เคด ถูกพัฒนาขึ้นในฐานะเกมลำดับที่สองบนตู้ "Rewritable Stage" ของ Namco โดยมีเป้าหมายให้เป็น "Idol Produce Manager Game" คือเกมที่ผู้เล่นสัมผัสประสบการณ์เป็นโปรดิวเซอร์ไอดอลอย่างเต็มรูปแบบ ตู้เกมประกอบด้วยสองส่วนหลัก:

🖥️Station

จุดเล่นเกมหลักที่มีหน้าจอสัมผัสสำหรับผู้เล่นโปรดิวซ์ไอดอลของตัวเอง

📺Live Tower

จอแสดงผลขนาดใหญ่ที่แสดงผลการเล่นของผู้เล่นในร้านแบบเรียลไทม์ ทำให้เกิดการ "โชว์ผลงาน" ของไอดอลที่ถูกโปรดิวซ์ผ่านสายตาของผู้เล่นคนอื่น

🎮 โครงสร้างการเล่น

การผูกเกมเข้ากับเครือข่ายระดับประเทศทำให้จัดอันดับโปรดิวเซอร์และไอดอลได้ ซึ่งสร้างแรงจูงใจให้ผู้เล่นกลับมาเล่นบ่อย ๆ เพื่อรักษาตำแหน่งในแรงกิ้ง ขณะเดียวกันตู้ Live Tower ทำให้ผู้คนที่เดินผ่านไปมาเห็นภาพ PV ของไอดอลที่ถูกโปรดิวซ์ และสนใจเข้าร่วมเป็นโปรดิวเซอร์เอง

แม้ในระยะแรกจะมีเสียงคัดค้านภายในบริษัทว่าแนวคิดเช่นนี้จะ "ขายไม่ออก" เพราะเป็นการนำธีมไอดอลมาสู่อาร์เคดในยุคที่ตลาดเกมจีบสาวอยู่บนคอนโซลและ PC เป็นหลัก แต่การทดสอบในสถานที่จริง (Local Test) เช่น ที่ร้านเกมในนากาโนะ กลับพบว่ามีผู้เล่นต่อคิวจำนวนมาก และบรรยากาศการแข่งขันในร้านทำให้ทีมพัฒนาได้รับการยืนยันว่าโครงการมีศักยภาพเชิงตลาด การตอบรับนี้ทำให้ Namco ตัดสินใจเดินหน้าพัฒนาเต็มตัว:

กลไกเกม โปรดิวเซอร์ และนวัตกรรมเชิงธุรกิจ

01

บทบาท "โปรดิวเซอร์" ในฐานะ Player Identity ใหม่

ความสำคัญของอาร์เคด Idolmaster ไม่ได้อยู่แค่การนำธีมไอดอลมาเป็นเกม แต่คือการสร้าง "บทบาทโปรดิวเซอร์" ขึ้นใหม่ ผู้เล่นไม่ได้ถูกเชิญชวนให้จินตนาการว่าตนเองเป็นแฟนหนุ่มของไอดอล แต่เป็นผู้จัดการอาชีพที่ต้องตัดสินใจเชิงยุทธศาสตร์ เช่น ฝึกซ้อมด้านใด จัดตารางงานอย่างไร เข้าร่วมออดิชันไหน ภายในขอบเขตของ "สัญญา" ที่มีเวลาจำกัดและเป้าหมายชัดเจน — สะท้อนโมเดลของวงการไอดอลจริงในญี่ปุ่นที่ต้องแข่งขันสูงและมีการวางแผนอาชีพอย่างเข้มข้น ทำให้ผู้เล่นได้สัมผัส "โครงสร้างธุรกิจ" ของไอดอลผ่านรูปแบบเกมเชิงระบบ

02

เครือข่ายออนไลน์ระดับประเทศ กับ "เศรษฐกิจการแข่งขัน"

ผู้เล่นแข่งขันแรงกิ้งกับโปรดิวเซอร์คนอื่นผ่านระบบเน็ตเวิร์ก และเห็นอิทธิพลของการโปรดิวซ์ที่ดีเลิศในรูปของแฟนคลับที่เพิ่มขึ้นและตำแหน่งในแรงกิ้ง ระบบนี้สร้างกลไก "พีระมิด" ที่มีโปรดิวเซอร์ระดับบนเป็นผู้กำหนดมาตรฐาน และผู้เล่นทั่วไปพยายามไล่ตาม ส่งผลให้การเล่นไม่ใช่แค่การบริโภคเนื้อหา แต่เป็นการเข้าร่วมใน "เศรษฐกิจการแข่งขัน" ที่สร้างคุณค่าและชื่อเสียงในคอมมูนิตี้

03

ต้นแบบการมีชีวิต "ข้ามสื่อ" ตั้งแต่ยุคต้น

อาร์เคด Idolmaster เริ่มทดลองเชื่อมต่อกับโทรศัพท์มือถือและบริการออนไลน์ เพื่อส่งอีเมลจากไอดอลถึงโปรดิวเซอร์ และกิจกรรมเสริมอื่น ๆ ที่ทำให้ตัวละครมีชีวิต "ข้ามสื่อ" ตั้งแต่ยุคต้น แม้ภายหลังบริการเครือข่ายของเวอร์ชันอาร์เคดจะถูกยุติในปี 2010 และตู้เกมเข้าสู่โหมดออฟไลน์ แต่นวัตกรรมเหล่านี้กลับกลายเป็นต้นแบบให้กับแฟรนไชส์ Idolmaster ในรูปแบบเกมคอนโซล มัลติมีเดีย และมือถือในทศวรรษต่อ ๆ มา

การต่อยอดสู่ Project iM@S และแฟรนไชส์ย่อย

ความสำเร็จเชิงคอนเซ็ปต์ทำให้ Namco ขยายโครงการสู่ "PROJECT IM@S" ซึ่งประกาศให้ Idolmaster กลายเป็น IP มัลติมีเดียอย่างเต็มรูปแบบ ครอบคลุมเกมคอนโซล แผ่นเพลง ซีดีดรามา อนิเมะ และอีเวนท์ไลฟ์ของนักพากย์ จุดสำคัญคือการย้ายศูนย์กลางจากตู้เกมอาร์เคดไปสู่คอนโซล Xbox 360 ในปี 2007 ซึ่งทำให้แฟนคลับติดตามไอดอลผ่านเนื้อหาที่ลึกขึ้นและเน้นเรื่องเล่า จนเกิดฐานแฟนคลับออนไลน์จำนวนมากผ่านแพลตฟอร์มอย่าง Nico Nico Douga ที่เต็มไปด้วยวิดีโอ AMV และ MAD ของ Idolmaster

การเปิดตัวตัวละครใหม่อย่าง Hoshii Miki บน Xbox 360 ทำให้จำนวนไอดอลเพิ่มจาก 9 เป็น 11 คน และก่อรูป "ไฟจราจร 3 สี" คือชุดสามตัวละครหลักที่มีสีประจำตัวแตกต่างกัน และถูกใช้เป็นแกนของการตลาดในภาคต่อ ๆ มา ขณะเดียวกันการประกาศ PROJECT IM@S ในปี 2006 เป็นสัญญาณว่าบริษัทมอง Idolmaster ไม่ใช่แค่เกมเดียว แต่เป็นแพลตฟอร์ม IP ที่จะถูกแตกเป็นหลายซีรีส์ย่อย รวมถึงการเชื่อมต่อกับนักพากย์ในฐานะ "ไอดอล 3D" ที่แสดงบทบาทตัวละครนั้นบนเวทีจริง

🧬 การมองแบบธุรกิจ

การเกิดขึ้นของซีรีส์ย่อยอย่าง Cinderella Girls, Million Live, Shiny Colors และล่าสุด Gakuen Idolmaster จึงต้องถูกมองในฐานะ "การแตกแบรนด์" ภายในกรอบ IP เดิมที่เริ่มต้นจากอาร์เคด โดยแต่ละซีรีส์พัฒนาโมเดลธุรกิจที่แตกต่างกันตามยุคของแพลตฟอร์มและความคาดหวังของตลาด

🎤PART 03 · IDOLMASTER

การขยายตัวของแฟรนไชส์ Idolmaster: จาก 765PRO สู่ Gakuen Idolmaster

765PRO และยุคคอนโซล–อนิเมะ

แกนหลักดั้งเดิมของ Idolmaster คือสาย "765 Production" หรือที่แฟนมักเรียกว่า "ต้นตำหรับ (本家)" ซึ่งเริ่มต้นจากอาร์เคดและขยายสู่ Xbox 360, PS3 และอนิเมะทีวี ซีรีส์นี้สร้างภาพของไอดอลหญิงยุคแรก เช่น Amami Haruka, Kisaragi Chihaya และ Takatsuki Yayoi ในฐานะ "ต้นแบบ" ของไอดอล 2D ที่แฟนรู้จักกันอย่างกว้างขวาง ในเชิงธุรกิจ 765PRO คือรากฐานสำคัญที่สร้างแบรนด์ Idolmaster ให้เป็นที่รู้จัก และวางแบบแผนการเชื่อมต่อระหว่างเกม เพลง และไลฟ์ของนักพากย์

การออกอนิเมะทีวีในปี 2011 ทำให้ Idolmaster เข้าสู่ตลาดอนิเมะแผ่นดิสก์และเพลงในวงกว้าง แต่ในด้านรายได้จากเกม แกน 765PRO พบว่าการพึ่งพาคอนโซลเพียงอย่างเดียวไม่เพียงพอเมื่อเข้าสู่ยุคเกมมือถือและโซเชียลเกมในต้นทศวรรษ 2010 แฟรนไชส์จึงต้องขยายไปยังแพลตฟอร์มใหม่และกลุ่มลูกค้าใหม่ผ่านซีรีส์ย่อย ซึ่งนำไปสู่การเกิดของ Cinderella Girls และ Million Live ในท้ายที่สุด

Cinderella Girls: จากโซเชียลเกมสู่เกมมือถือ

'IDOLMASTER Cinderella Girls' เริ่มต้นจากโซเชียลเกมบน Mobage โดยมีคอนเซ็ปต์ "โปรดิวซ์ไอดอลจำนวนมาก" ผ่านระบบการ์ดสะสม ซึ่งสะท้อนการขยายฐานตัวละครไปสู่จำนวนหลายร้อยคน และเปิดพื้นที่ให้แฟนสามารถยึดติดกับ "ไอดอลรอง" ที่อาจไม่ได้อยู่ในสายหลัก 765PRO

จุดเด่นเชิงธุรกิจคือการใช้โมเดล free-to-play และการ์ดกาชา เพื่อสร้างรายได้อย่างต่อเนื่อง ซึ่งแตกต่างจากเกมคอนโซลที่รายได้ส่วนใหญ่เกิดจากการขายแผ่นครั้งเดียว การมาของเกมมือถือ 'Starlight Stage' ยิ่งเสริมให้ Cinderella Girls กลายเป็น IP เกมมือถือที่สำคัญของ Bandai Namco ในยุคเดียวกับ Love Live! School Idol Festival และต่อมากับ Shiny Colors

แม้จะไม่มีตัวเลขรายได้ตรงที่เปิดเผย เช่นเดียวกับที่มีการรายงานสำหรับ Uma Musume หรือ Gakuen Idolmaster แต่จากบริบทตลาดเกมมือถือและการอยู่ในอันดับต้น ๆ ของยอดขายเป็นเวลานาน สามารถประเมินได้ว่าซีรีส์นี้มีรายได้ระดับ หลายหมื่นล้านเยน ตลอดช่วงชีวิตของเกม และมีฐานแฟนคลับกว้างขวางในกลุ่มผู้เล่นมือถือ

ในด้านไลฟ์คอนเสิร์ต Cinderella Girls จัด "ไลฟ์" ขนาดใหญ่ที่นักพากย์ขึ้นเวทีในฐานะตัวละคร ร้องเพลงที่แฟนรู้จักจากเกม พร้อมการใช้โปรเจกชั่นและเวทีที่ผสมผสานโลก 2D และ 3D การจัดไลฟ์เหล่านี้ไม่เพียงเพิ่มรายได้จากบัตรและสินค้า แต่ยังเสริมความผูกพันระหว่างแฟนกับ IP ทำให้ฐานแฟนคลับมีความยั่งยืนและพร้อมสนับสนุนสินค้าใหม่ ๆ ต่อเนื่อง

Million Live: โมเดล "ไลฟ์" และการสร้างฐานแฟนพันธุ์ลึก

'IDOLMASTER Million Live' ถูกพัฒนาขึ้นเพื่อขยายจำนวนไอดอลและเปิดพื้นที่ให้กับนักพากย์รุ่นใหม่ โดยเน้นคอนเซ็ปต์ "โรงละคร" และการแสดงไลฟ์ที่ต่อเนื่อง เหมือนที่ชื่อเกมมือถือภาคหลังคือ 'Million Live! Theater Days' สื่อถึงความสำคัญของเวทีและโรงละครในเรื่องเล่า ในเชิงธุรกิจ Million Live แตกต่างจาก Cinderella Girls ในการเน้นการสร้าง "แฟนคลับเดนตาย" ที่ให้ความสำคัญกับการเข้าร่วมไลฟ์จริงและการติดตามนักพากย์ในฐานะศิลปินมากขึ้น

แม้ไม่มีตัวเลขยอดขายเกมมือถือที่เปิดเผยตรง ๆ แต่จากบริบทของตลาด การจัดไลฟ์ขนาดใหญ่หลายครั้ง และการทำอนิเมะทีวีในเวลาต่อมา สามารถเห็นได้ว่าซีรีส์นี้ถูกวางตำแหน่งเป็น "เสาหลัก" อีกเสาหนึ่งของ IP Idolmaster ซึ่งสร้างรายได้ผ่านทั้งเกม เพลง และกิจกรรมไลฟ์ ในระดับที่แม้จะไม่เทียบเท่า Cinderella Girls ในช่วงพีค แต่ก็มีความสำคัญเชิงโครงสร้างของ IP

Shiny Colors และ Gakuen Idolmaster: ยุคเกมมือถือเชิงบริการ

'IDOLMASTER Shiny Colors' ในฐานะเกมบราวเซอร์และมือถือ ที่เน้นการเล่นเชิงจำลองการโปรดิวซ์แบบลึกและเนื้อเรื่องขนาดใหญ่ สะท้อนว่าตลาดไอดอล 2D ในยุคปลายทศวรรษ 2010 เริ่มแบ่งออกเป็นสองเส้น คือเส้น "เกมริธึม / กาชา" อย่าง Cinderella Girls และ Love Live! กับเส้น "ซิมูเลชันโปรดิวซ์" ที่เน้นการอ่านเนื้อเรื่องและพัฒนาตัวละครแบบลึก Shiny Colors จึงสามารถดึงกลุ่มแฟนที่สนใจด้านเรื่องเล่ามากกว่าเกมจังหวะ และสร้างรายได้ผ่านแพ็กเกจในเกมและสินค้าเกี่ยวกับตัวละคร

ส่วน 'Gakuen IDOLMASTER' ถือเป็นจุดเปลี่ยนสำคัญในยุคล่าสุด เพราะเป็นการกลับไปเน้น "ประสบการณ์โปรดิวซ์" บนเกมมือถืออย่างเต็มตัว ใช้ระบบภาพสามมิติ และนำเสนอตัวละครในบริบทยุคใหม่ของโรงเรียนไอดอล เกมนี้เปิดให้บริการในปี 2024 ในฐานะ "แบรนด์ที่ 6" ของซีรีส์ Idolmaster และถูกผลักดันอย่างหนักจนสามารถขึ้นอันดับหนึ่งของยอดขายเกมมือถือในญี่ปุ่นในช่วงหนึ่งของปี 2026

🤝PART 09 · IMPACT ON 3D IDOLS

ผลกระทบต่ออุตสาหกรรมไอดอล 3D และการปรับตัวเชิงธุรกิจ

หนึ่งในคำถามหลักของงานนี้คือ อุตสาหกรรมไอดอล 2D หญิงส่งผลอย่างไรต่ออุตสาหกรรมไอดอล 3D หรือ "ศิลปินไอดอลจริง" ในญี่ปุ่น — โดยเฉพาะในมิติธุรกิจ ไม่ใช่มิติพฤติกรรมแฟนคลับ ในการตอบคำถามนี้ ต้องมองที่โครงสร้างรายได้และแบบแผนการจัดการศิลปินของทั้งสองฝ่าย:

01

นักพากย์หญิงกลายเป็นทรัพยากรสำคัญของบริษัท

นักพากย์ไม่ได้เป็นเพียงผู้พากย์เสียงตัวละคร แต่กลายเป็นผู้แสดงไลฟ์คอนเสิร์ต ผู้ร่วมอีเวนท์ และตัวแทน IP ในโลกจริง โมเดลนี้เห็นชัดใน Idolmaster, Love Live!, BanG Dream! และ Uma Musume ที่นักพากย์ขึ้นเวทีในบทบาทตัวละคร โดยมีความคาดหวังให้มีทักษะการร้อง เต้น หรือเล่นเครื่องดนตรีในระดับหนึ่ง บริษัทจึงต้องลงทุนเทรนนักพากย์คล้ายบริษัทไอดอล และพัฒนาระบบจัดการตารางงานไลฟ์และอีเวนท์ — ขยายขอบเขตธุรกิจของวงการนักพากย์ไปใกล้กับวงการไอดอลจริง

02

IP 2D ยั่งยืนกว่าศิลปินบุคคล

บริษัทบันเทิงที่เคยทำไอดอล 3D เช่นค่ายเพลงหรือต้นสังกัดไอดอล บางรายหันมาลงทุนใน IP 2D เพราะมองว่า IP มีความยั่งยืนกว่าศิลปินบุคคลที่มีอายุงานจำกัดและเสี่ยงต่อการลาออกหรือดราม่า การลงทุนใน IP 2D เปิดโอกาสให้เปลี่ยนตัวนักพากย์หรือสร้างรุ่นใหม่เข้ามาโดยยังรักษาตัวละครเดิมหรืออย่างน้อยรักษาแบรนด์ไว้ — ตัวอย่างเช่น Bushiroad ใช้ BanG Dream! เป็น IP หลัก แต่วงในโลกจริงอย่าง Roselia สามารถเปลี่ยนสมาชิกบางคนได้ ในขณะที่ตัวละครในอนิเมะยังคงอยู่

03

แย่งพื้นที่ในตลาดไลฟ์คอนเสิร์ตและสินค้าแฟนคลับ

อุตสาหกรรมไอดอล 2D และ VTuber จัดไลฟ์ในฮอลล์ขนาดใหญ่ที่ใช้ทรัพยากรคล้ายคอนเสิร์ตของไอดอลจริง เช่น ฮอลล์โดม สนามกีฬา หรือฮอลล์ในเมืองใหญ่ การแข่งขันแย่งวันจัดฮอลล์และงบประมาณของผู้บริโภคระหว่าง IP 2D กับวงไอดอลจริงจึงเพิ่มขึ้น ในบางช่วงเวลาแฟนคลับอาจต้องเลือกว่าจะซื้อบัตรคอนเสิร์ตของวงไอดอลจริงหรือของ IP 2D เช่น Love Live! หรือ Idolmaster ส่งผลให้รายได้ฝั่งหนึ่งเพิ่มในขณะที่อีกฝั่งสูญเสียส่วนแบ่งตลาด

04

"ไอดอลเสมือน" คู่แข่งโดยตรงในตลาดออนไลน์

Hololive และ VTuber ทำให้รูปแบบ "ไอดอลเสมือน" กลายเป็นคู่แข่งตรงของไอดอลจริงในตลาดออนไลน์ เพราะแฟนสามารถบริโภคคอนเทนต์ผ่าน YouTube โดยไม่ต้องออกจากบ้าน และสนับสนุนผ่าน superchat หรือ merchandise ได้อย่างต่อเนื่อง ค่ายไอดอลบางแห่งจึงเริ่มทดลองใช้ VTuber หรือแพลตฟอร์มออนไลน์เสริมศิลปินจริง เช่น รายการไลฟ์สตรีมมิงของไอดอล หรือการใช้ avatar ในบางคอนเทนต์ — เป็นการปรับตัวเชิงธุรกิจเพื่อลดความเหลื่อมล้ำด้านเทคโนโลยีและตอบสนองแฟนรุ่นใหม่

05

อิทธิพลย้อนกลับ: จากไอดอล 3D สู่ไอดอล 2D

ความสัมพันธ์ระหว่างสองอุตสาหกรรมเป็นแบบสองทิศทาง — โมเดล "งานอีเวนท์จับมือ" ที่แฟนพบปะศิลปินตัวจริง ถูกดัดแปลงเป็นอีเวนท์พบปะนักพากย์หรืออีเวนท์ลายเซ็นสำหรับแฟน IP 2D การจัด "คาเฟ่ธีมไอดอล" ที่นำอาหารและสินค้า IP มาให้บริการ ก็ได้รับแรงบันดาลใจจากคาเฟ่ของวงไอดอลจริง — อุตสาหกรรมไอดอล 3D จึงไม่ได้เป็นฝ่ายถูกแย่งส่วนแบ่งเพียงฝ่ายเดียว แต่ส่งอิทธิพลกลับด้านภาพลักษณ์และแบบแผนการจัดกิจกรรมเช่นกัน

Nico Nico Douga, Twitter และ YouTube ทำให้แฟนสร้างเนื้อหา UGC (User-Generated Content) เช่น วิดีโอ MAD และแฟนอาร์ต ซึ่งช่วยโปรโมต IP โดยบริษัทไม่ต้องเสียค่าใช้จ่าย — กรณี Idolmaster การแพร่หลายของวิดีโอ Remix และ MAD บน Nico Nico Douga ช่วง 2007–2010 สร้างฐานแฟนที่ลึกและทำให้ IP ถูกยอมรับในวงกว้าง ในยุคหลัง Twitter และ YouTube ยิ่งทำให้การสื่อสารกับแฟนคลับเร็วและต่อเนื่อง ผ่านการโปรโมตอีเวนท์และไลฟ์ของ Love Live!, BanG Dream!, Uma Musume และ Hololive

สังเคราะห์ภาพรวม

อุตสาหกรรมไอดอล 2D หญิงในญี่ปุ่นมีวิวัฒนาการเชิงธุรกิจที่ซับซ้อนและเชื่อมโยงกับอุตสาหกรรมอื่นอย่างแนบแน่น — ตั้งแต่การกำเนิดในอาร์เคด 'THE IDOLM@STER' ที่สร้างบทบาทโปรดิวเซอร์และแนวคิด "สนับสนุนไอดอล" ผ่านเครือข่ายออนไลน์ ไปจนถึงการขยายตัวของมีเดียมิกซ์ใน Love Live! และ Aikatsu! ที่นำอนิเมะ เกม และสินค้าไปเชื่อมกับไลฟ์คอนเสิร์ตและคอนเทนต์ทัวริซึม ในยุคเกมมือถือ แฟรนไชส์อย่าง Cinderella Girls, Love Live! SIF และ BanG Dream! ใช้โมเดล free-to-play และกาชาสร้างรายได้ต่อเนื่อง จากนั้น Uma Musume และ Hololive ยกระดับมาตรฐานรายได้และฐานแฟนคลับไปสู่ระดับใหม่ — Uma Musume สร้างรายได้ระดับร้อยพันล้านเยนต่อปีจากเกมมือถือ และ Hololive สร้างโครงสร้าง VTuber โปรดักชันที่มีรายได้หลายหมื่นล้านเยนต่อปีจากการสตรีม ไลฟ์ และสินค้า

ต่ออุตสาหกรรมไอดอลจริง (3D): ไอดอล 2D หญิงเปลี่ยนบทบาทนักพากย์ให้กลายเป็นศิลปินที่บริษัทต้องดูแลและพัฒนาทักษะไม่ต่างจากไอดอล บริษัทบันเทิงจำนวนมากเริ่มมองว่า IP เป็นทรัพย์สินที่ยั่งยืนกว่าศิลปินบุคคล และใช้โมเดลการจัดไลฟ์คอนเสิร์ตและสินค้าแฟนคลับที่ได้แรงบันดาลใจจากไอดอลจริงมาให้บริการแฟน IP 2D ในบางกรณี วงไอดอลจริงก็เริ่มใช้เทคโนโลยี VTuber หรือ avatar เพื่อปรับตัวเข้ากับเศรษฐกิจคอนเทนต์ที่ Hololive และ VTuber สร้างขึ้น

จากอุตสาหกรรมอื่น: เกมมือถือ free-to-play เป็นตัวเร่งสำคัญที่ทำให้ IP อย่าง Cinderella Girls, Love Live!, BanG Dream!, Uma Musume และ Gakuen Idolmaster สร้างรายได้ต่อเนื่องและแข่งขันกันในตลาดเดียวกัน เครือข่ายสังคมออนไลน์และแพลตฟอร์มสตรีมมิงทำให้การโปรโมตต่อเนื่องและการสร้าง UGC ง่ายขึ้น คอนเทนต์ทัวริซึมอย่างกรณี Numazu พิสูจน์ว่าคอนเทนต์ไอดอล 2D สร้างเศรษฐกิจในโลกจริงได้ในระดับเมือง และ VTuber แสดงให้เห็นว่า IP เสมือนสามารถสร้างรายได้และผู้ชมระดับโลก โดยไม่จำเป็นต้องมีเกมหรืออนิเมะเป็นแกน
