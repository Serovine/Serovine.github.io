## 1. ไกด์แบบมักง่ายสำหรับสอนใช้ AI Image Generator

### 🔍 ขั้นที่ 1: หารูปที่ชอบ แล้วดูโมเดลที่เขาใช้

เริ่มต้นง่ายๆ ด้วยการหารูป AI ที่คุณถูกใจก่อน เมื่อเจอแล้ว ให้เข้าไปดูรายละเอียดของรูปนั้นว่าศิลปินใช้ **Base Model** ตัวไหนในการสร้าง

### ⚙️ ขั้นที่ 2: ดูรายละเอียดและการตั้งค่าจากคนทำโมเดล

เข้าไปดูที่หน้าของโมเดลนั้นๆ โดยปกติคนที่ทำโมเดลแจกมักจะเขียน **Template Prompt** มาตรฐานและแนะนำการตั้งค่าไว้ให้แล้ว

ถ้าหาไม่เจอ ให้คัดลอกการตั้งค่ามาจากคนที่สร้างรูปที่คุณชอบได้เลย โดยเน้นโฟกัสที่ **3 ค่าหลัก**:

| การตั้งค่า | คำแนะนำ |
|:---|:---|
| **Sampler Method** | ส่วนใหญ่เลือก `Euler a` |
| **Sampling Steps** | ส่วนใหญ่ตั้งที่ **20 – 30** |
| **CFG Scale** | ส่วนใหญ่ตั้งที่ **5 – 9** |

> ⚠️ **ข้อควรระวังเรื่อง LoRA:** อย่าลืมเช็คว่าภาพนั้นมีการใช้ LoRA ประเภท **Reduce Cost** (พวกลดต้นทุน/ลดเวลาเจน) หรือไม่ ถ้ามีการใช้ คุณสามารถปรับ Sampling Steps ให้ต่ำลงเหลือแค่ **8** ก็สามารถสร้างภาพสวยๆ ได้แล้ว

### 🚀 ขั้นที่ 3: ใส่ Prompt เลือกขนาด แล้วลุยเลย!

เมื่อได้ข้อมูลครบแล้ว:

1. ✅ ใส่ **Prompt** ที่ต้องการลงไป
2. ✅ คัดลอกการตั้งค่า 3 อย่างจากด้านบนมาใส่
3. ✅ เลือกขนาดรูป (**Resolution**) ที่ต้องการ
4. ✅ กด **Generate** — จบ!

## 2. อธิบายประเภทโมเดล AI ภาพแบบคร่าวๆ

การเข้าใจประเภทของโมเดลจะช่วยให้คุณเลือกใช้งานได้ตรงจุดมากขึ้น

### 🧩 ประเภทของโมเดล

| โมเดล | คำอธิบาย |
|:---|:---|
| 🏗️ **Base Model / Checkpoint** | โมเดลหลักที่เป็นโครงสร้างพื้นฐานสำหรับใช้สร้างภาพ |
| 🎯 **LoRA / LyCORIS** | โมเดลขนาดเล็ก (*Low Rank Adaptive*) ใช้เสริมเพื่อควบคุมรายละเอียด เช่น สไตล์ลายเส้น เสื้อผ้า หรือตัวละคร |
| 🚫 **Embedding** | โมเดลขนาดเล็กที่ใช้เขียนคำสั่ง *ห้าม* (Negative) ไม่ให้ AI ทำสิ่งที่เราฝังไว้ เช่น ห้ามวาดมือเละ ห้ามวาดผิดสัดส่วน |
| 🔧 **ADetailer Model** | โมเดลที่ใช้ *แก้ไขรูปที่สร้างมาแล้ว* โดยเฉพาะ มักใช้ซ่อมใบหน้าหรือมือให้ดูดี ไม่เบี้ยว ไม่เละ |

---

### 🔬 ความแตกต่างระหว่าง E-pred กับ V-pred

|  | 🅴 **E-pred** (Epsilon Prediction) | 🆅 **V-pred** (V-Prediction) |
|:---|:---|:---|
| **หลักการ** | ทำนาย *noise* (ความผิดพลาด) ที่ถูกเติมลงในภาพ | ทำนายค่าผสมระหว่าง noise และภาพต้นฉบับ |
| **สมการ** | `target = noise` | `v = α_t · ε − σ_t · x` |
| **ผลลัพธ์** | รายละเอียดชัดเจน คมชัด สีสันสดใสเป็นธรรมชาติ | ภาพ "อ่อนนุ่ม" ละมุนขึ้น แสงและเงาดูเป็นธรรมชาติ |

---

### 📜 โมเดลยุคบุกเบิก: Stable Diffusion (SD)

จุดเริ่มต้นที่ทำให้วงการ AI วาดรูปเติบโต:

```
SD  →  SD 1.5  →  SDXL
│         │           │
│         │           └── รองรับความละเอียดสูงขึ้น + เข้าใจ Prompt ดีขึ้น
│         └── ได้รับความนิยมสูง + ฐานชุมชนนักพัฒนาใหญ่ที่สุด
└── โมเดลแรกเริ่ม
```

---

## 3. คำศัพท์เฉพาะกิจสำหรับ AI Image

### 📖 อภิธานศัพท์

| ศัพท์ | คำอธิบาย |
|:---|:---|
| **Sampler Method** | อัลกอริทึมที่ใช้ลบจุดรบกวน (Noise) เพื่อสร้างภาพ — เช่น `Euler a` (เร็ว) และ `DPM++ 2M Karras` (สมดุล) |
| **Sampling Steps** | จำนวนก้าวในการสุ่มสร้าง — ยิ่งมาก ยิ่งละเอียด แต่ใช้เวลานานขึ้น |
| **CFG Scale** | ค่าความยึดติดกับ Prompt — ค่าน้อย = AI มีอิสระ / ค่ามาก = AI ทำตามคำสั่งเป๊ะๆ |
| **LoRA** | ใช้ดึง Style นักวาด, ลดต้นทุน/เวลา (Reduce Cost), หรือล็อคหน้าตาตัวละคร |
| **Embedding** | โมเดลฝังคำสั่ง ใช้ *ห้าม* ไม่ให้วาดสิ่งที่เราไม่ต้องการ |
| **VAE Model** | ตัวปรับสี — ถ้าภาพดูซีด การใส่ VAE จะช่วยให้สีสดและอิ่มตัวขึ้น |
| **ADetailer** | ตัวช่วยอัตโนมัติหลังเจนภาพเสร็จ ซ่อมใบหน้า/มือที่เบี้ยวให้กลับมาดูดี |
| **ControlNet** | เครื่องมือขั้นสูง ต้องเพิ่มรูป *Image Control* เพื่อบังคับให้ AI วาดตามท่าทางหรือโครงสร้างที่ต้องการ |

---

> 🧠 **ข้อสรุป:** สุดท้ายแล้ว จำแค่ **4 อันแรก** ก็เพียงพอ ส่วนการตั้งค่าให้ดูคำแนะนำจากคนปล่อยโมเดลเป็นหลัก — อันไหนคนทำไม่ได้พูดถึง ก็ใช้ **ค่า Default** ได้เลย

## 4. ส่วนสุดท้าย: โครงสร้าง Prompt และเทคนิค

แต่ละ Base Model มักมีโครงสร้างไม่เหมือนกัน แต่อาจใกล้เคียงกัน เช่น:

| โมเดล | ลักษณะเด่น |
|:---|:---|
| 🦄 **Pony** | ใช้ `_` (Underscore) แทนการเคาะวรรค เช่น `score_9_up`, `score_8_up` |
| 🎬 **Animagine** | มักมี `, BREAK ,` เพื่อแบ่งแยกส่วนของ Prompt ออกจากกันอย่างชัดเจน |

---

### 🏗️ โครงสร้างของ Illustrious Prompt

ครอบคลุมหลายเวอร์ชัน เช่น **WAI-illustrious, ZUKI Anime ILL, Nova Illustrious, Perfect Illustrious, VXP Illustrious, Hassaku XL**

```
[Score]  →  [Year Modifier]  →  [Rating]  →  [Artist]  →  [Person Count]  →  [Character]  →  [General Tags]
```

| ลำดับ | ส่วนประกอบ | ความสำคัญ | ตัวอย่าง |
|:---:|:---|:---|:---|
| 1 | **Score** (คะแนนความสวย) | ⭐ ควรใส่ | `masterpiece` |
| 2 | **Year Modifier** (ปี) | ❌ ไม่จำเป็น | `newest` |
| 3 | **Rating** (เรทภาพ) | ❌ ไม่จำเป็น | `general` |
| 4 | **Artist** (นักวาด) | 🔹 ไม่บังคับ แต่ถ้าใส่จะได้ลายเส้นที่ดี | `itomugi-kun` |
| 5 | **Person Count** (จำนวนคน) | ⭐ ควรใส่ให้ชัดเจน | `1girl`, `2boys` |
| 6 | **Character Name** (ชื่อตัวละคร) | ❌ ไม่ต้องใส่ เว้นแต่ต้องการเจาะจง | `kinoshita hideyoshi` |
| 7 | **General Tags** (รายละเอียดทั่วไป) | 🔹 คำสั่งอื่นๆ ที่เหลือ | `building`, `outdoors` |

