รูปแบบการเขียน (Format)

บทความ SCP เขียนเหมือนรายงานทางวิทยาศาสตร์หรือเอกสารลับ — ประกอบด้วยหมายเลข SCP, Object Class, Special Containment Procedures, คำอธิบาย และบันทึกการทดลอง

ระบบกฎเกณฑ์ (Rule System)

ระบบ Object Class จัดประเภทความยากในการกักกัน, ระบบ Security Clearance สำหรับบุคลากร, และกฎการเขียนที่ชัดเจนเพื่อรักษาคุณภาพ

การขยายตัวของจักรวาล

"Tales" เป็นเรื่องราวยาวที่เชื่อมโยงกับจักรวาล SCP และกลุ่มองค์กรภายนอก (GOIs) ที่มีเป้าหมายและวิธีการแตกต่างกัน เช่น Chaos Insurgency, GOC, Serpent's Hand

ตอนนี้ SCP Foundation มีบทความเกิน 10,000+ ตัวแล้ว — และนี่ยังไม่นับรวม "Lost Series" บทความที่ถูกลบออกเป็นการถาวรด้วยเหตุผลต่างๆ เช่น ปัญหาลิขสิทธิ์ ถูกฟ้องร้อง หรือคุณภาพไม่ถึงมาตรฐาน บางตัวใน Lost Series กลายเป็นตำนานในตัวเอง เพราะคนที่เคยอ่านตอนที่มันยังอยู่ก็ค่อยๆ นำเรื่องราวมาเล่าให้คนรุ่นหลังได้ฟัง

06 // HIERARCHY

ระดับชั้นในองค์กร

ระบบลำดับชั้นแบ่งออกเป็น 3 ระบบย่อย ที่ทำงานคู่กันแต่มีความหมายต่างกัน

6.1 ระดับชั้นบุคลากร (Personnel Classes)

ระบุ "คุณค่าชีวิตและหน้าที่" — ใครอพยพก่อน ใครเข้าหาความตายก่อน

CLASS A มันสมอง — ห้ามเข้าใกล้ SCP เด็ดขาด — อพยพอันดับ 1
CLASS B ปฏิบัติการ — สัมผัส Safe/Euclid เท่านั้น — อพยพรองจาก A
CLASS C ทั่วไป — ไอที, ช่างซ่อม, ยาม — รู้แค่ว่ามีสิ่งประหลาด
CLASS D ชุดส้ม ใช้แล้วทิ้ง — หนูทดลอง — เดินเข้าหาความตาย
CLASS E ผู้ติดเชื้อ — เจ้าหน้าที่ที่สัมผัส SCP แล้วเกิดอาการแปลก — ถูกลดขั้นมาขังแยก
CLASS ระดับ คำอธิบาย
A สูงสุด บุคลากรระดับมันสมอง — ผู้บริหารระดับสูง หัวหน้าสถานี นักวิทยาศาสตร์ระดับปรมาจารย์ ห้ามเข้าใกล้ห้องกักกัน SCP เด็ดขาด เพราะถ้าตายหรือโดนสะกดจิต ความรู้ทั้งหมดจะรั่วไหล
B สูง เจ้าหน้าที่ระดับปฏิบัติการ — นักวิจัยระดับกลาง ทหารรักษาความปลอดภัยที่สัมผัส SCP ที่ "ค่อนข้างปลอดภัย" (Safe/Euclid บางตัว) อพยพรองจาก Class A
C กลาง เจ้าหน้าที่ทั่วไป — ไอที ช่างซ่อม พนักงานทำความสะอาด ยามเฝ้าประตู รู้แค่ว่ามีสิ่งประหลาด แต่ ไม่มีสิทธิ์รู้รายละเอียดลึกๆ
D ต่ำสุด แก๊งชุดส้ม ใช้แล้วทิ้ง — หนูทดลองมนุษย์ ไม่มีสิทธิ์อะไร ไม่มีระดับการเข้าถึงข้อมูล เดินเข้าหาความตายเพื่อเก็บข้อมูล
E พิเศษ ผู้ติดเชื้อ/กักตัวชั่วคราว — เจ้าหน้าที่ที่สัมผัส SCP แล้วเกิดอาการแปลก ถูก ลดขั้นทันที ถ้าหายก็กลับคลาสเดิม ถ้าไม่หาย... ก็อาจกลายเป็น SCP ตัวใหม่

6.2 ระดับการเข้าถึงข้อมูล (Security Clearance)

ระบบ "พาสเวิร์ด / การ์ดสี" — แยกจาก Personnel Classes คนเสื้อขาวอาจมี Level 2–3 ในขณะที่ยาม (Class C) อาจมีแค่ Level 0–1

LVL 0
FOR OFFICIAL USE ONLY
พนักงานทำความสะอาด, เสมียนหน้าห้อง
รู้แค่ชื่อองค์กร ไม่รู้ว่ามี SCP ตัวไหนอยู่ในตึกบ้าง
LVL 1
CONFIDENTIAL
เจ้าหน้าที่รักษาความปลอดภัยทั่วไป
รู้ข้อมูลเฉพาะ SCP ตัวที่ตัวเองมีหน้าที่ยืนเฝ้าหน้าห้องเท่านั้น
LVL 2
RESTRICTED
ระดับมาตรฐานของแก๊งเสื้อขาวและทหารทั่วไป
เข้าถึงข้อมูล SCP ส่วนใหญ่ระดับ Safe และ Euclid เพื่อทำการวิจัยและควบคุมสถานการณ์
LVL 3
SECRET
หัวหน้าโครงการวิจัย, ผู้บังคับบัญชาหน่วย MTF
เปิดอ่านเอกสาร SCP ระดับอันตราย (Keter) ได้ — คอยสั่งการแก๊งเสื้อขาวอีกที
LVL 4
TOP SECRET
Site Director, ผู้อำนวยการภูมิภาค
รู้ข้อมูลเกือบทั้งหมด — มีอำนาจ สั่งปิดตึก ลบความจำเจ้าหน้าที่ทุกคน หรือกดปุ่มระเบิดนิวเคลียร์ทำลายศูนย์วิจัย
LVL 5
THAUMIEL / OMNISCIENT
ผู้ที่ได้รับอนุญาตจาก O5 เท่านั้น
ระดับสูงสุด — เข้าถึง ความจริงทุกอย่างของจักรวาล เอกสารที่ถูกเซนเซอร์ [DATA EXPUNGED] คนระดับนี้มองเห็นเป็นตัวหนังสือปกติทั้งหมด
